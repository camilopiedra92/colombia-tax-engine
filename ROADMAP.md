# 🗺️ Roadmap

## Colombian Tax Engine - Development Roadmap

### ✅ v1.0.0 (Current)

- Complete Formulario 210 implementation
- 100% test coverage
- Zero dependencies
- Full compliance with Estatuto Tributario
- ICA optimization (cost vs. tax credit)
- Dividend discount lock
- Year-versioned tax profiles (2024, 2025, 2026)

### 🔮 v1.1.0 (Planned)

- [ ] Enhanced error messages with tax law references
- [ ] Validation helpers for input data
- [ ] Tax planning simulation mode
- [ ] What-if scenarios (compare strategies)
- [ ] Localized error and output messages (ES/EN)

### 🔮 v1.2.0 (Future)

- [ ] Formulario 110 support (personas jurídicas)
- [ ] IVA calculation module
- [ ] Retención en la fuente calculator
- [ ] DIAN calendar integration
- [ ] Tax regime comparison tool

### 🔮 v2.0.0 (Vision)

- [ ] Multi-country support architecture
- [ ] Plugin system for custom rules
- [ ] Real-time DIAN API integration
- [ ] AI-powered tax optimization suggestions
- [ ] Interactive tax planning dashboard (web component)
